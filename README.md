# tiny-stack-vm

[![make.fun · tiny-stack-vm-01-run-20261122](https://make.fun/badge/tiny-stack-vm-01-run-20261122.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122?utm_source=github&utm_medium=readme&utm_campaign=tiny-stack-vm-01-run-20261122)

A tiny stack virtual machine in a single `main.ts` (Node 22, TypeScript, no dependencies), built for make.fun's "Build a tiny stack virtual machine" bounty. It runs all 40 instances in one pass, byte-exact against the reference VM.
